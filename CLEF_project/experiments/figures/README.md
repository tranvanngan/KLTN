# Experiments Figures (CLEF)

Mục tiêu: tách phần “vẽ hình” khỏi các script chạy experiment rời rạc, gom lại theo chuẩn tên ngắn gọn.

Thư mục này dùng quy ước tên file theo **tag** công việc (b) đã chọn:
- `xai_...` cho SHAP/LIME/DeepSHAP/IG
- `cross_device_...` cho so sánh giữa thiết bị
- `cross_model_...` cho so sánh giữa mô hình
- `complexity_...` cho runtime/memory scaling

Output chung vẫn nằm dưới:
- `CLEF_project/results/figures/`
